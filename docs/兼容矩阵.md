## 语言、框架与宿主能力

- Java Mapper、XML、OGNL 和核心索引为基础能力。
- Kotlin K2、Spring、YAML 和 Database Tools 通过可选描述符隔离；缺少可选插件时核心能力必须继续加载。
- MyBatis-Plus 3.5.17、MyBatis-Flex 1.11.8 与 TkMapper 按锁定语料验证；运行项目版本超出已验范围时只使用可证明的公共语义，不伪造支持。
- Database Tools 不可用时可使用显式 Community JDBC 元数据；插件不捆绑或下载 JDBC 驱动。
- 支持 MySQL、PostgreSQL、Oracle、SQL Server、SQLite、H2 与达梦方言模型；实际数据库版本、驱动和权限仍由用户环境决定。

- 未进入本表的 IDE、EAP、第三方 IDE 分支或非标准 JRE。
- 动态运行期拼接的 namespace、statement id、表名、列名、Map 键和任意 OGNL 结果。
- 未显式选择的数据源、框架、版本、外键关系或生成目标。
- 未签名开发 ZIP 的生产分发、自动更新与 Marketplace 兼容性。
