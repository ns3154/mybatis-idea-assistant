# S3 精确引用、基础检查与安全修复任务卡

> 阶段：S3 导航、引用、基础检查与安全 Quick Fix
> 日期：2026-08-11
> 状态：已验收

## 目标

在 S2 统一语义模型和增量索引上交付可直接用于编辑器的精确引用、双向导航、保守 Inspection 与最小安全写入闭环。任何多目标关系都保留候选；任何无法证明安全的诊断或写入都默认关闭或停止。

## 固定边界

- 只按完整 namespace、符号类型、statement id、Provider 类型与方法名解析，不使用文件名、简单类名或目录距离猜测；
- 所有查询遵守调用元素的模块可见范围，跨模块无依赖时不得串入同名目标；
- Dumb Mode、索引竞态、项目关闭、失效 PSI 和取消请求必须静默降级或传播取消，不把异常显示给用户；
- 多候选通过平台选择器展示，不能静默采用索引或文件系统返回的第一个结果；
- 默认启用的检查必须具有低误报边界；namespace、未使用 statement、缺失 `@Param` 等存在合法动态语义的检查默认关闭；
- 写操作必须使用 IntelliJ ModCommand 提供预览与单次 Undo，只写用户明确选择的目标；只读、目标变化、重复声明或路径冲突时停止；
- 未使用 statement 不提供删除修复，只允许定位精确 Mapper 接口，避免破坏字符串调用、框架调用或动态 SQL。

## 自动化复现

```bash
mvn --batch-mode --file samples/java-mybatis-minimal/pom.xml clean verify
mvn --batch-mode --file samples/semantic-corpus/pom.xml clean verify
./gradlew check verifyPluginProjectConfiguration verifyPluginStructure verifyPlugin
./scripts/verify-sandbox-lifecycle.sh 20
./scripts/verify-optional-dependency-isolation.sh
```

真实 IDE 验收固定使用副屏独立沙箱，按精确应用路径控制，不操作用户主屏上的 IDEA。自动化负责验证 Quick Fix 的预览、实际写入和单次 Undo；实机只验证导航、告警与动作注册，不在用户项目执行危险写入。
