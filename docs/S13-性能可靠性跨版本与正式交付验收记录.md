- 新增 100 万行、2000 个 Mapper、10000 个 statement、四个模块命名维度和四个数据源命名维度的扫描夹具；逐 Mapper 校验全部符号，P95 低于 50ms 的硬断言通过；

- 全量测试在 2025.2 SDK 下复现并修复 MCP statement 预览在 Undo 后读取陈旧 PSI 范围的问题：索引 PSI 只用于确定文件，候选偏移改由当前未保存 `Document` 的新解析结果计算；

- MCP 的意外运行期异常写入本机诊断日志，对客户端仍只返回无路径、无堆栈的资源化安全错误；
- 全仓源码与最终 ZIP 未发现本机绝对路径、GitHub token、私钥或发布 token 内容。
