# 安装与首次使用

## 安装候选 ZIP

1. 从受信任的 GitHub Release 或 CI 制品下载插件 ZIP，不要解压。
2. 核对发布页提供的 SHA-256；正式版还必须核对签名验证结果与 SBOM。
3. 在 IntelliJ IDEA 的插件设置中选择“从磁盘安装插件”，选中 ZIP 并按提示重启。
4. 打开项目后等待索引完成。插件默认离线，不会启动本地 MCP，也不会连接数据库或上传源码。

本仓库开发构建的 ZIP 位于 `build/distributions/`。未签名的本地包只用于开发验收，不应作为正式发布包分发。

## 15 分钟首次使用路径

### 1. 识别 Mapper

准备一个 Java 或 Kotlin Mapper 接口，以及 namespace 与接口全限定名一致的 MyBatis XML：

```java
package com.example;

public interface UserMapper {
    User findById(long id);
}
```

```xml
<mapper namespace="com.example.UserMapper">
    <select id="findById" resultType="com.example.User">
        select id, name from user where id = #{id}
    </select>
</mapper>
```

插件只使用可证明的全限定名、statement id、注解和配置，不按文件名猜测对应关系。索引完成后，Mapper 方法与 XML statement 左侧会出现双向导航图标。

### 2. 完成第一次跳转

- 点击 Java 方法左侧图标跳到 XML statement。
- 点击 XML `id` 左侧图标跳回 Java/Kotlin 方法。
- 存在重复 XML 或 Java 重载时，平台展示全部候选，不静默选择第一个。

### 3. 查看检查与补全

- 对不存在的 statement、表、列、参数路径或 ResultMap 属性，插件只在语义足够确定时提示。
- 在索引中、目标不唯一、动态标识符或不完整语法下，插件会静默降级。
- 高误报风险检查默认关闭，可在 IDE Inspection 设置中按团队需要启用。

### 4. 完成第一次安全生成预览

在 Database Tools 中明确选择已加载的表，再执行 MyBatis 生成动作；Community 环境可显式配置 JDBC 驱动、URL、用户和 schema。生成流程先展示全量计划和差异，确认前不写文件。执行后应立即验证一次 Undo/Redo。

不要在第一次使用时启用 SQL 写执行或 MCP 写工具。需要时先阅读 [隐私说明](隐私说明.md) 和 [发布、升级与回滚](发布升级与回滚.md)，在测试项目中验证权限、预览、确认、撤销与回滚。

## 卸载

1. 若启用了 MCP，先在设置中关闭并确认回环端口已释放。
2. 关闭正在运行的数据库读取或生成操作。
3. 在插件设置中禁用或卸载并重启 IDE。

卸载不得修改项目源码或数据库。插件索引和缓存可由 IDE 清理或重建；已经由用户确认生成的文件应使用 IDE Undo、Local History 或版本控制恢复。

遇到问题时查看 [常见问题与故障排查](常见问题与故障排查.md) 和 [兼容矩阵](兼容矩阵.md)。
