# S6 OGNL 语言支持任务卡

> 阶段：S6 OGNL 语言、类型、引用与编辑器能力
> 日期：2026-08-12
> 状态：开发完成，待 S6 最终统一验收

## 目标

为 MyBatis `test`、`bind/value` 等表达式建立可恢复的 OGNL 词法、语法、PSI、类型和引用模型，并消费 S4 参数上下文与 S5 动态 SQL 词法绑定。S6 不执行用户表达式，不把 Map/动态对象猜成确定 Java 类型，不通过反射或求值调用项目代码。

## 固定边界

- 词法器和语法器对任意输入都必须线性前进；错误以稳定代码和半开范围返回，不用异常文本当协议；
- 运算符优先级、属性/方法/索引链、列表/Map 字面量、三元、静态成员和 `#` 变量必须形成不可变 AST；
- XML `test`、`when/test`、`bind/value` 使用同一个注入语言和 ParserDefinition，不复制三套解析器；
- `_parameter`、`_databaseId`、Mapper 参数、bind 与 foreach item/index 按词法位置进入上下文；声明前不可见，离开 foreach 不泄漏；
- null、未知 Map 键、原始集合、动态下标、重载歧义和不安全方法保持 unknown，不报告可证明性不足的问题；
- 静态类型/成员只按模块可见的精确全限定名解析；不初始化类、不执行方法、不扫描文件系统；
- Dumb Mode、索引竞态、失效 PSI、项目关闭和取消必须类型化停止，取消异常原样传播；
- 任何 Rename 必须走 IntelliJ 原生引用与预览/Undo，动态键或多目标不能写入。

## S6-A 验收矩阵

| 编号 | 场景 | 必须输出 | 保守边界 |
|---|---|---|---|
| S6-A-01 | 标识符与字面量 | null、布尔、数字、单/双引号、转义及精确范围 | 未闭合字符串产生错误节点并继续到 EOF |
| S6-A-02 | 一元/二元运算 | `not/!`、算术、比较、相等、`and/or` 按 OGNL 优先级成树 | 不求值、不做常量执行 |
| S6-A-03 | 链式表达式 | 属性、方法调用、参数列表、方括号索引 | 缺失名称、括号或下标时保留前缀 AST 并报告最小错误 |
| S6-A-04 | 条件与集合 | 三元、列表、Map、`in/not in` | 不展开集合，不执行 contains |
| S6-A-05 | 静态与上下文变量 | `@FQN@member`、静态调用、`#name` | 缺类名/成员名类型化报错，不猜简单类名 |
| S6-A-06 | 稳定性 | 随机 Unicode、超长链、深嵌套和取消 | 线性前进，无死循环、栈溢出或吞取消 |

## S6-B～D 统一门禁

- ParserDefinition、注入器、CompletionContributor、ReferenceContributor 与 Inspection 必须从真实扩展点取得实例测试；
- 常见 MyBatis OGNL 正例零系统性误报；只有静态可证明不存在的属性/方法/变量才报告；
- 1000 token 文件解析节点线性；热缓存补全 P95 小于 150ms，使用算法预算和多次分位数共同证明；
- 当前产物通过 Gradle/Maven、最低 261 Verifier、20/20 生命周期、5/5 可选依赖隔离及有效副屏 IDEA 实机。

只有 S6-A～S6-D 全部满足并留下当前产物证据，S6 才能标记“已验收”。
