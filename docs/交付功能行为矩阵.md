## 3. 固定失败原则

- 所有读操作可取消；项目关闭、Dumb Mode、索引竞态和失效 PSI 不得泄漏异常到用户界面。
- 所有写操作默认先预览，并由单个 IDE 命令承载 Undo；冲突时停止，不猜测覆盖。
- 数据库、Spring、Kotlin、YAML 等可选依赖不可用时，仅关闭对应能力，不得导致主插件类加载失败。
- 默认不联网、不监听端口、不记录凭证、SQL 参数、项目路径或源码内容。
- 任何多目标关系都保留候选；排序只影响展示，不改变语义正确性。
