## 已实现范围

- 新增与 Database Tools 解耦的确定性生成配置、表/列请求、产物和计划模型；支持 Standard 与显式 MyBatis-Plus 模板组；
- 支持表前缀、实体后缀、字段排除、属性名/Java 类型/TypeHandler 覆盖、数据库注释、自增键、单/复合/无主键及方言关键字转义；
- 带时区 JDBC 类型保留为 `OffsetTime`/`OffsetDateTime`，完整输出已支持的 MyBatis JDBC 类型名；MySQL、Oracle 与支持 `DEFAULT VALUES` 的方言分别生成合法的空列插入形式；Java 类型、TypeHandler 或生成类之间存在短名冲突时在生成前拒绝；
- 在内存中生成 Entity、Mapper、Mapper XML 和 Service，并对每个候选文件做 Java/XML PSI 语法与根结构校验；
- 每个生成区带稳定 ID 和正文 SHA-256；只替换指纹仍匹配的生成区，所有区域外 Java/XML 文本保持不变；
- 计划器统一返回新建、更新、无变化和类型化冲突；路径碰撞、只读、目录占位、语法错误、标识缺失/损坏/变化或生成区手改均在任何写入前停止；
- 读取已有文件时优先消费未保存 `Document`，执行前再次复核项目根、目标状态和当前文档，防止预览后并发变化；
- 新建目录/文件和更新文件合成为单个命名 IDE Command；真实平台测试证明整批更新可一次 Undo、一次 Redo，失败预检不会产生部分文件，创建或更新中途异常会恢复已有文档并删除本批文件与空目录；
- Database Tools 可选描述符注册数据库右键动作；动作只接受有效、非 LOADING 的已选表，不触发连接或刷新；
- 提供基础包、源码/资源根、模板组、表前缀、实体后缀、四类产物、注释和关键字转义配置，并支持确定性文本导入/导出；
- 写入前提供全量状态、按文件选择、候选文本和 IntelliJ 原生 diff；冲突存在时禁用生成；执行前创建 Local History 系统标签。

## 关键保守边界

- 生成动作只读取用户明确选中的已加载表；不主动连接、刷新、执行 SQL 或读取凭证；
- MyBatis-Plus 只有用户显式选择对应模板组时生成，不探测或猜测项目框架；
- 没有主键时不生成按主键读取、更新和删除；复合主键参数显式使用 `@Param`；
- 未知 JDBC 类型回退为 `Object`，自定义 Java 类型与 TypeHandler 只能来自显式配置；
- 用户改过任一生成区时整批停止；插件不把用户修改吞回新指纹，也不尝试三方猜测合并；
- 预览存在任一冲突时不能通过取消选择该文件继续写，避免跨文件模型不一致；
- 当前 UI 自动化证明注册、选择守门和底层计划/命令行为；真实对话框、diff、数据库树和 Local History 视觉路径仍必须在副屏实机验收。
