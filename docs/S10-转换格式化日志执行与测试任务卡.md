# S10 转换、格式化、日志、执行与测试任务卡

> 阶段：S10 SQL 工具链与测试骨架
> 日期：2026-08-12
> 状态：开发完成，自动质量门通过；待生命周期、可选依赖隔离与副屏实机验收

## 目标

在不执行项目代码、不隐式写文件、不隐式连接数据库的前提下，提供可审计的 SQL/DDL/Java 转换、MyBatis XML 格式化、官方日志形态 SQL 还原、显式参数面板、受控 SQL 执行和 Mapper JUnit 4/5 测试骨架。任何类型、投影、事务或来源无法证明的情况都必须拒绝，或在预览中使用明确的 `Object`/`OTHER` 降级并要求人工确认。

## 固定边界

- 所有文本工具默认只在本机内存中处理，不联网、不保存输入、不记录 SQL、参数、结果、凭证或项目路径；
- 日志还原只解析 MyBatis 官方常见 `Preparing`/`Parameters` 形态，按线程上下文和 FIFO 配对；缺行、截断、二进制和占位符不一致时不输出半成品 SQL；
- 问号替换只发生在正常 SQL 词法上下文，引号、注释、反引号、方括号标识符和 PostgreSQL dollar quote 中的 `?` 不替换；
- XML 格式化保留动态标签、CDATA、注释、多行标签内部文本和原换行风格；结构不完整时零写入；连续两次格式化结果必须相同；
- `CREATE TABLE` 转换只接受单表 DDL；未知类型降级到 `OTHER` 并标记确认；复用 S8 生成器输出 Entity、Mapper 和含 ResultMap 的 XML；
- SELECT 转换只接受单条、以 `SELECT` 开头、具有 `FROM` 的显式投影；不支持 `*`，复杂表达式必须写 `AS`；结果 JDBC 类型未知时生成 `Object`/`OTHER` 并显示警告；
- Java 转 DDL 只读取 PSI，不加载类、不执行注解处理器；支持常用 MyBatis-Plus/JPA 注解、继承字段、注释和索引；未知类型与方言降级必须展示；
- 快速执行只接受一条词法完整 SQL 和最多 500 个显式 `TYPE:value` 参数；`#{}`/`${}` 必须先解析；二进制参数拒绝；
- SELECT/SHOW/DESCRIBE/VALUES 等只读分类无需危险确认；写入、DDL、WITH/EXPLAIN 等未知分类均需风险确认和精确输入 `执行危险SQL`；
- Database Tools 执行入口只在可选描述符注册；使用受管连接引用、显式事务、30 秒超时、200 行结果上限和主动取消；只读查询回滚，危险 SQL 仅在双确认后提交；数据库自行自动提交的 DDL 明确提示无法保证回滚；
- JUnit 骨架支持 JUnit 5/Jupiter 与 JUnit 4，只生成预览；泛型 Mapper/泛型方法和非抽象接口方法明确拒绝，不写测试文件、不启动测试上下文。
