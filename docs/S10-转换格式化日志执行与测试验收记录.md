> 日期：2026-08-12

## 已实现范围

- 解析 MyBatis 官方常见日志形态，按线程上下文和 FIFO 配对 `Preparing`/`Parameters`，安全处理 null、数字、布尔、时间、枚举、JSON/字符串和特殊字符；二进制、截断、数量错配与不唯一参数边界不输出半成品；
- 使用统一 SQL 词法扫描器处理单/双引号、反引号、方括号、行/嵌套块注释和 PostgreSQL dollar quote，提供问号替换、单/多语句识别和 READ_ONLY/WRITE/DDL/UNKNOWN 风险分类；
- MyBatis XML 格式化保留动态标签、CDATA、注释、多行标签内部与 LF/CRLF，结构错误时失败；预览后以单个 IDE Command 写入并支持 Undo；
- `CREATE TABLE` 生成 Entity、Mapper、ResultMap XML；Java PSI 生成六方言 DDL；显式 SELECT 生成 Mapper 方法、XML statement、ResultMap 和 Java 行模型；全部先预览且不自动写入；
- 参数面板支持 STRING、LONG、DECIMAL、BOOLEAN、DATE、TIMESTAMP 和显式 JDBC NULL，限制 500 个并拒绝二进制；
- Database Tools 可选入口执行单条 SQL：只读回滚，危险 SQL 双确认后提交，失败回滚；30 秒超时、200 行上限、超长/二进制结果脱敏、主动 statement cancel；
- Mapper 方法生成 JUnit 5/Jupiter 或 JUnit 4 只读骨架，提供常见参数默认值和 TODO 注入位置，不运行项目类、不写文件。
