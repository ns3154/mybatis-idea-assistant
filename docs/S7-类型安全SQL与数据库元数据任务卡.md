# S7 类型安全 SQL 与数据库元数据任务卡

> 阶段：S7 SQL PSI、方言、数据库元数据、补全与检查
> 日期：2026-08-12
> 状态：开发完成，当前候选本地统一门已通过，待远端与副屏验收

## 目标

消费 S5 的符号化动态 SQL 与字符级 source map，把有界、连续的虚拟 SQL 接入 IntelliJ SQL PSI；在 Database Tools 可用时读取已加载的数据源元数据，为表、列、别名、函数和关键字提供补全与可证明检查。数据库插件、连接或元数据不可用时，OGNL、导航、引用和非数据库能力必须继续工作。

## 固定边界

- 虚拟 SQL 不穷举动态条件组合；`choose` 使用有序代表分支并显式记录被折叠的分支，节点数保持线性；
- `#{}` 只转换为参数占位符，`${}` 转换为显式动态标识符；不执行 OGNL 或替换运行期值；
- SQL 错误、引用与补全范围必须经 S5 source map 回到原 XML；合成字符不能伪装成精确原文；
- SQL PSI、方言类和 Database Tools API 只从可选数据库描述符加载；禁用数据库插件时主插件不得类加载失败；
- 元数据接口不暴露 Database Tools 类型，为 Community/JDBC 适配保留相同模型；
- 元数据读取只消费已加载模型，不在编辑器查询路径主动连接、刷新或索取凭证；
- 所有提供方调用在后台执行，可取消、可超时；项目关闭、连接断开、加载中和异常均返回类型化状态；
- 不存在表/列、歧义列、resultMap 列缺失和类型不匹配只在元数据完整且目标唯一时报告。

## S7-A 验收矩阵

| 编号 | 场景 | 必须输出 | 保守边界 |
|---|---|---|---|
| S7-A-01 | 静态 SQL 与 include | 保持 S5 文本顺序和跨文件字符来源 | 不丢失 entity/CDATA 映射种类 |
| S7-A-02 | `#{}`/`${}` | 分别生成 `?` 与稳定动态标识符 | 完整占位符映射为 DECODED，不把表达式当 SQL |
| S7-A-03 | if/foreach/trim | 单条有界代表 SQL，动态片段前后连续 | foreach 只建一个代表迭代，不展开集合 |
| S7-A-04 | choose | 选择第一个 when 或 otherwise 代表分支并产生折叠诊断 | 不生成分支笛卡尔积，不声称覆盖全部运行期路径 |
| S7-A-05 | 错误与生命周期 | 非法占位符保留文本并诊断；取消原样传播 | 不缓存瞬时失败，不吞 `ProcessCanceledException` |

## S7-B～D 统一门禁

- SQL PSI、方言、Database Tools 适配必须从真实可选扩展或服务注册取得实例测试；
- Database Tools 禁用时通过隔离启动，核心描述符不得直接引用数据库实现类；
- 数据源断开、加载中、schema 切换、同名表和多数据源均有类型化正反例；
- 数据库对象引用只消费与当前 Database Tools 数据源修改计数一致的 READY 快照；表列目标与 XML source map 都必须唯一，Find Usages 复用同一引用定义；
- 无 WHERE update/delete 检查默认关闭，只对没有动态标识符且代表 SQL 确定的直接 statement 报告；
- ResultMap `column` 补全和缺失映射 Quick Fix 只消费 READY 且唯一的单表结果；Quick Fix 必须在执行前复核 resultMap 源文本、物理文件、元数据修改计数和完整计划，任一变化即零写入；
- 元数据提供方调用线程不得为 EDT；超时和取消不得遗留后台任务或缓存失败；
- 当前产物通过 Gradle/Maven、最低 252 Verifier、加固生命周期 1 次报告审查后同 HEAD 100/100、5/5 可选依赖隔离及有效副屏 IDEA 实机。
