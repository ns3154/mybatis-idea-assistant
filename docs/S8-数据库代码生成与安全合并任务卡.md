# S8 数据库代码生成与安全合并任务卡

> 阶段：S8 数据库表生成、稳定生成区、全量预览与原子写入
> 日期：2026-08-12
> 状态：开发完成，待最终统一质量门与副屏验收

## 目标

用户在 Database Tools 中明确选择一张或多张已经加载的表后，插件在内存中生成 Entity、Mapper、Mapper XML 和 Service 候选文件。所有目标必须先形成完整计划并允许按文件选择、查看候选文本和原生差异；写入只能更新指纹仍匹配的稳定生成区，必须保留生成区外的手写内容，并由一个 IntelliJ 命令承载整批 Undo/Redo。

## 固定边界

- 只读取用户当前选择且 Database Tools 已经加载的 `DbTable`；不连接、刷新、执行 SQL 或索取凭证；
- 核心生成器只消费自有不可变表/列模型，不引用 Database Tools 类型；数据库动作只由可选数据库描述符注册；
- 模板、命名、字段过滤、注释、关键字转义、类型/TypeHandler 覆盖和产物集合均来自显式配置，不按类路径猜框架；
- 全部文件先在内存中生成并经 Java/XML PSI 解析；任何路径碰撞、语法错误、只读、标识缺失、指纹变化或不完整标识均使整批计划进入冲突状态；
- 只替换带稳定 ID 和 SHA-256 指纹、且指纹与现存正文一致的生成区；生成区外一律视为手写区；
- 未保存文档文本优先于磁盘文本，是预览、合并和执行前 TOCTOU 复核的事实源；
- 真正写入前再次复核项目根、父目录、目标存在性、可写性和当前文本；失败时零写入；
- 整批创建/更新合成为单个命名 IDE Command，执行前创建 Local History 系统标签，写入异常时在同一写锁内回滚，并支持一次 Undo 与一次 Redo；
- 标识缺失或用户改过生成区时不尝试猜测合并，不自动重建或覆盖原文件。

## 验收矩阵

| 编号 | 场景 | 必须输出 | 保守边界 |
|---|---|---|---|
| S8-01 | 单表或多表选择 | 每表生成用户勾选的 Entity/Mapper/XML/Service；路径稳定排序 | 多表产生相同路径时整批冲突，不覆盖任一文件 |
| S8-02 | 命名与类型 | 表前缀、实体后缀、字段过滤、属性名/Java 类型/TypeHandler 覆盖生效 | 非法包名、路径、重复属性或空产物集合在生成前拒绝 |
| S8-03 | 主键与方言 | 单主键、复合主键、无主键、自增键及六类方言关键字正确输出 | 无主键时不伪造按主键更新/删除；未知类型回退 `Object` |
| S8-04 | schema 新增/删除/重命名/改类型 | 只更新稳定生成区，所有手写 Java/XML 内容保持不变 | 用户改过生成区、标识缺失或标识集合变化时停止 |
| S8-05 | 未保存编辑与格式 | 预览包含未保存手写内容；LF/CRLF 保持原文件风格 | 不以磁盘旧文本覆盖编辑器当前文档 |
| S8-06 | 预览与选择 | 写入前显示全量状态、候选文本，支持按文件选择和原生 diff | 任一冲突存在时禁用生成，不允许通过取消勾选绕过全量冲突 |
| S8-07 | TOCTOU 与失败恢复 | 执行前变化、只读、目录冲突和父目录变化均在写入前停止 | 失败不得留下部分目录、空文件或部分更新 |
| S8-08 | Undo/Redo 与 Local History | 整批更新一次 Undo 全部恢复，一次 Redo 全部重做；生成前存在标签 | 不把每个文件拆成独立命令 |
| S8-09 | 可选依赖 | Database Tools 存在时在数据库右键菜单显示；缺失时核心插件可加载 | 核心描述符和生成核心不得引用 JetBrains 数据库类型 |
| S8-10 | 100 组黄金门 | 100 组 add/delete/rename/type/composite/no-PK 演进重复生成幂等且手写内容零丢失 | 黄金摘要变化必须显式审查，不自动更新基线 |

## 统一门禁

- 当前产物必须通过 Gradle 全量测试、Checkstyle、真实分包 JaCoCo、两个 Maven 语料、项目配置、插件结构、最低 261 Plugin Verifier 和 ZIP 构建；
- S8 生成核心行覆盖率不得低于 85%，整体覆盖率不得低于 70%；
- 当前产物必须完成 20/20 生命周期与 5/5 可选依赖隔离；
- 检测到真实副屏后，只在副屏 IDEA 2026.1 中验证数据库右键入口、配置导入导出、多表预览、diff、冲突禁写、Local History、Undo/Redo 和未保存编辑；
- 以上自动化、隔离、生命周期和副屏实机全部通过前，S8 只能标记“开发完成，待最终统一验收”。
