## 2. 阻断规则

出现以下任一情况时，不得关闭对应批次：

- 已知错误会跳到错误 Mapper 或错误 statement；
- XML 修改、撤销或移动后仍使用陈旧目标；
- 索引期间出现未捕获异常或 EDT 明显卡顿；
- 构建产物依赖未声明的本地文件、个人绝对路径或本机缓存；
- Plugin Verifier 出现新增阻断；
- 公开仓库包含凭证、数据库口令、私有样例或来源不明的第三方代码；
- 样例 `mvn clean verify` 失败。
- B02 无法稳定区分“无 Mapper XML”和“statement 缺失”，或索引版本升级后仍读取旧缓存；
- B03 在同名接口或 Java 重载场景静默选择单一目标；
- B04 对无 Mapper XML、重载、默认/静态方法、注解 SQL 或 `@Flush` 产生误报，或尝试自动修改 XML；
- B04 Inspection 退化为全项目扫描、无界重试，或未建立查询性能守门；
- S2 XML/配置索引器创建 PSI、解析外部实体或在索引中查询项目类；
- S2 在无依赖模块间串联 Mapper、XML、配置、MapperScan 或 TypeAlias；
- S2 10 万 statement 实际索引查询、未保存编辑、Kotlin K2 或可选依赖隔离回归失败；
- 最低 2026.1 GA 兼容验证失败。
- S3 任一多目标引用或导航静默选中第一个，或跨不可见模块串联；
- 默认检查对合法动态 namespace、字符串调用或隐式参数名产生系统性误报；
- Quick Fix 缺少预览/单次 Undo，目标路径不可辨识，或在只读、冲突、失效场景仍写入；
- “未使用 statement”出现自动删除动作；
- S4 把未知 Map 键、完整 OGNL、foreach/bind 局部变量或不稳定实际参数名报告为确定错误；
- ResultMap 把只读属性当作可写属性，或 TypeAlias 冲突/不可见模块被静默选成单一目标；
- `@Param` Rename 在动态 OGNL、重载、注解 SQL、无法解析 include、只读或失效目标存在时仍写入任一文件；
- S5 动态条件发生组合爆炸，source map 不连续或把解码/合成字符标成 EXACT；
- include 重复目标被静默选中、循环未停止、合法运行期 `${}` 被当作缺失 property；
- 未保存 statement/fragment、索引或 Dumb 状态变化后仍返回陈旧动态 SQL 缓存；
- OGNL 解析器对错误输入不前进、发生栈溢出、吞取消，或在语法诊断存在时继续产生语义误报；
- OGNL 把动态 Map/上下文/重载歧义报告为确定缺失，或跨不可见模块选择静态类型；
- entity 解码范围未经回映射就进入引用、Inspection 或 Rename；
- bind/foreach Rename 越过词法作用域、发生冲突仍写入，或不能由单次 Undo 完整恢复；
- S7 代表 SQL 发生分支组合爆炸，或把代表路径结果宣称为全运行期正确；
- SQL 注入抢占完整或未闭合 MyBatis 参数范围，导致既有参数引用、补全或 Rename 回归；
- 元数据提供方在 EDT 连接/刷新数据库、等待 I/O、索取凭证，或取消/超时后仍持续写缓存；
- 数据源/schema/表目标不唯一时静默选中一个候选，或 Database Tools 模型变化后仍消费旧快照；
- 禁用 `com.intellij.database` 后核心导航、引用、OGNL 或非数据库检查无法加载；
- ResultMap 缺列/类型检查在复合 column、多表、动态表列、LOADING 或未知类型场景产生确定警告；
- 生成器覆盖稳定区外手写内容，或在生成区指纹不匹配、标识缺失/损坏时仍写入；
- 多文件生成未先完成全量计划/TOCTOU 复核，失败后留下部分目录或文件，或不能由一次 Undo 全部恢复；
- 计划忽略未保存 Document，按磁盘旧版本合并或执行；
- 数据库生成动作主动连接、刷新、执行 SQL、索取凭证，或禁用 `com.intellij.database` 后核心插件无法加载；
- 方法名语法存在多种合法解释却仍生成，或更新/删除没有谓词；
- 动态可选条件在 OR 树中被省略，导致生成 SQL/Wrapper 布尔语义变化；
- Plus/Flex 未经显式框架和版本选择，或生成结果不能在锁定真实依赖下编译；
- Join 未经用户选择 FK/PK 关系、类型和输出字段，按名称猜测或绕过方言拒绝；
- S9 动作引入 IntelliJ 内部 API，或 Database Tools 缺失时污染核心类加载；
- 日志配对、占位符或 SQL 词法不唯一时仍输出可执行半成品；
- XML 格式化不幂等、改变 CDATA/注释/动态标签，或跳过预览/TOCTOU/单次 Undo；
- SELECT 转换接受 `*`、复杂无别名投影或静默猜测结果类型；Java 转 DDL 执行项目类；
- 快速执行允许多语句、隐式参数、未双确认危险 SQL，或取消后仍无限等待/读取；
- 插件日志或对象字符串表示泄漏 SQL、参数、结果、凭证或项目路径；
- JUnit 骨架自动写文件、启动框架/数据库，或对无法安全表达的泛型来源继续生成；
- 注解 SQL 参数在动态 Map 或不完整注入范围产生确定误报，或注解迁移在重载、附加属性/注解、动态 script、多 XML、已有 statement、只读或并发变化下仍写入；
- Spring 注入导航仅凭字段名、类型名或 `@Qualifier` 猜测 Mapper，静默选取重复 XML，或禁用 Spring 后导致主插件类加载失败；
- Kotlin K2 扩展把多个 light method 静默选成一个、解析真实字符串插值、错误回映射转义范围、与平台 gutter 合并异常，或禁用 Kotlin 后污染核心类加载；
- MCP 非回环可达、鉴权/白名单任一绕过、关闭后仍监听，或写工具未经过 preview→confirm/TOCTOU/Undo；
- 设置导出、日志、测试报告、SBOM、ZIP 或工作流包含明文密码、MCP token、私钥或发布 token；
- 中英文资源键不对称、注册 Action 文字为空，或正式版仍存在未登记的用户界面硬编码；
- SBOM 同一版本和依赖锁下不可复现，发布密钥缺失仍继续，或未验证签名便创建公开正式制品；

## 3. 风险关闭要求

风险只有具备可复现证据时才能标记“关闭”：

1. 写明控制措施已经落在哪个实现或测试中；
2. 记录实际运行命令和结果；
3. 对 IDE 交互类风险补充目标版本的人工验收记录；
4. 若只是降低概率而未消除，状态应为“已控制”，不能写“关闭”；
5. 重新打开风险时保留历史原因，不覆盖旧结论。

## 4. 每次公开发布前的最低检查

```bash
# 插件工程
./gradlew check verifyPluginProjectConfiguration verifyPluginStructure verifyPlugin verifyCyclonedxBom

# 独立样例
mvn --batch-mode --file samples/java-mybatis-minimal/pom.xml clean verify
mvn --batch-mode --file samples/semantic-corpus/pom.xml clean verify

# 启动与依赖隔离
./scripts/verify-sandbox-lifecycle.sh 20
./scripts/verify-optional-dependency-isolation.sh

# Git 提交范围与敏感内容由仓库维护者在推送前复核
git status --short
git diff --cached --check
```

每次提交/PR 的最低兼容基线为 IntelliJ IDEA 2026.1 GA；定时或手动任务补充验证 2026.2。真实发布还必须检查依赖许可证、SBOM、插件签名，并在目标版本复核 ZIP 的安装、禁用、卸载和重启；S1 的 2026.1 GA 生命周期证据不能替代后续版本的发布验收。
