## 1. 交付范围

本阶段把 S2 统一模型转化为 IntelliJ 原生编辑器能力：

- XML 引用：`mapper/@namespace`、statement `id`、`refid`、`resultMap`、`extends` 与逗号分隔引用；
- Java 引用与导航：Mapper 接口/方法 Find Usages、继承 Mapper 方法、注解 SQL、Provider 类型与方法；
- 基础 Inspection：缺失 Mapper XML、缺失 statement、无效 namespace、重复/未使用 statement、缺失 `@Param`；
- 安全修复：创建 Mapper XML、创建四类 statement、为单个/全部参数添加 `@Param`；
- 非破坏动作：未使用 statement 只定位精确 Mapper 接口，不提供删除；
- 生命周期：模块隔离、多候选、未保存编辑、Dumb Mode、索引竞态、失效 PSI、项目关闭和取消请求均有保守行为。
