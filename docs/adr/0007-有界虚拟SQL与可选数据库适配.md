# ADR-0007：有界虚拟 SQL 与可选数据库适配

- 状态：已接受
- 日期：2026-08-12
- 决策范围：S7 虚拟 SQL、方言、SQL PSI 和数据库元数据
- 关联文档：`docs/S7-类型安全SQL与数据库元数据任务卡.md`

## 背景

MyBatis statement 同时包含静态 SQL、运行期条件、循环、include、`#{}` 和 `${}`。直接把 XML 文本逐块注入 SQL 会割裂语句；穷举所有动态分支又会指数增长。Database Tools 只在部分 IDE/安装中可用，且数据源可能断开、加载中或需要凭证，不能成为核心导航和编辑能力的强依赖。

## 决策

### 1. S5 program 是虚拟 SQL 唯一输入

S7 不重新遍历 XML 猜动态标签，而是消费 S5 的不可变节点和 source map。静态文本保留 EXACT/DECODED/SYNTHETIC；参数占位符规范化后仍映射到完整原范围。

### 2. 代表路径有界而非分支穷举

if 保留一次 body，foreach 保留一次代表迭代，trim 生成显式前后缀；choose 使用有序第一个 when，缺少 when 时使用 otherwise，并记录分支折叠诊断。该结果用于编辑器 PSI 连续性，不代表运行期 SQL 求值或覆盖所有路径。

### 3. 核心元数据模型不依赖 Database Tools

数据源、schema、表、列、键与 SQL 类型使用项目自有不可变记录。提供方接口只接受项目、自有请求和取消指示器；Database Tools 适配器只存在于可选描述符。后续 JDBC/Community 适配必须实现同一接口，不改变调用方。

### 4. 只读已加载模型

编辑器分析不主动连接、刷新、弹凭证框或执行 SQL。Database Tools 适配器读取当前已加载模型并标记 READY/LOADING；没有完整快照时检查静默，补全可返回已有但明确标记的候选。

### 5. 异步边界在聚合服务统一执行

元数据提供方永不在 EDT 调用。聚合服务统一处理取消、超时、项目关闭、提供方失败和结果合并；瞬时失败不缓存。检查和补全只能消费已完成快照，不能在 EDT `join` 或阻塞等待。

## 结果

- 动态 SQL 的编辑器视图保持线性和可回映射；
- Database Tools 缺失或连接不可用不会破坏核心插件；
- 代表路径可能遗漏其他 choose 分支的 SQL 错误，因此诊断必须标记不完整，不能据此宣称全路径正确；
- S8 可以复用稳定元数据模型和异步边界，不直接依赖 JetBrains 数据库对象生命周期。
