# 常见问题与故障排查

## 看不到导航图标或检查

先确认 IDE 已完成索引，Java/Kotlin 接口有稳定全限定名，XML 根为未加前缀的 `mapper`，且 `namespace` 与接口全限定名完全一致。statement 必须是 Mapper 直接子元素，`id` 不能为空。索引中、文件语法不完整、目标不唯一或项目正在关闭时，插件会保守静默。

若刚完成 Undo、移动、重命名或修改未保存文档，先等待当前写命令完成再重试。持续不恢复时执行 IDE 的索引重建，并保留对应时间段的 `idea.log`。

## 为什么重复目标没有自动跳转

重复 Mapper XML、重复 statement 或 Java/Kotlin 重载都可能合法。插件不会猜测第一个目标，而是让平台展示全部候选；请先消除重复或选择正确目标。

## 为什么某些 SQL、OGNL 或参数路径不提示

动态表列名、任意 Map 键、字符串插值和运行期 OGNL 无法静态证明。插件宁可不提示，也不把猜测当作错误。可以把运行期值改成显式类型、固定注解或 XML 声明后再分析。

## Database Tools 动作不可用

确认使用的 IDE 包含并启用了 Database Tools，数据源模型已加载，且你在数据库树中明确选中了表。Community/Android Studio 环境请使用显式 JDBC 配置：驱动 JAR、URL、用户名、schema 和方言都必须提供，密码只保存在 PasswordSafe。插件不会自动下载驱动。

## 生成或重构为什么停止

常见原因包括：目标文件只读、未保存文本与计划不一致、稳定生成区已被手改、目标移动、重复候选、索引状态变化或预览令牌过期。不要绕过冲突；重新打开预览，核对差异后形成新计划。写入异常应自动回滚，仍需用 Undo、Local History 和版本控制复核。

## MCP 无法连接

- MCP 与写工具默认关闭；先在项目设置中显式启用。
- 服务只监听 `127.0.0.1`，拒绝非本机地址、Origin、不正确 Host、非 JSON POST、错误会话与错误 Bearer token。
- 端口变更、设置关闭、项目关闭或插件禁用会旋转令牌并停止旧会话。
- 不要把令牌写入仓库、日志、截图或设置导出。连接配置只应包含当前回环地址和当前内存令牌。

端口占用时换一个未使用端口；关闭后仍监听时记录端口、时间和 `idea.log`，不要强行发布候选。

## SQL 执行被拒绝或结果被截断

只允许单条语句。危险写 SQL 需要二次确认；只读语句使用回滚事务，写语句显式提交。结果最多保留 200 行和每单元 2000 字符，二进制只显示字节数；这是安全边界，不应通过配置取消。

## 如何收集最小问题信息

插件不含遥测，也不会自动上传问题。提交 Issue 前请主动提供：

1. IDE 产品、完整版本、系统和架构；
2. 插件版本、ZIP SHA-256 与安装来源；
3. 最小可复现 Mapper/配置，删除业务数据、SQL 常量、路径、用户名、URL、密码和 token；
4. 精确步骤、期望、实际结果和是否可稳定复现；
5. 仅截取问题时间范围的 `idea.log`，再次检查是否包含敏感信息。

不要上传完整私有项目、数据库导出、JDBC 密码、MCP token、签名私钥或 Marketplace token。安全漏洞请按 [安全策略](../.github/SECURITY.md) 的私密渠道报告。

## 仍无法解决

对照 [兼容矩阵](兼容矩阵.md) 确认版本是否在支持范围，并查看 [发布、升级与回滚](发布升级与回滚.md)。若问题只在新 IDE 出现，保留旧签名版本并回滚，不要用相同插件版本号覆盖现有制品。
