# ADR-0010：保守 SQL 工具链与受控执行

> 状态：已接受
> 日期：2026-08-12

## 背景

日志还原、格式化、双向转换和快速执行都会接触用户 SQL、参数、数据库连接与可写文件。若各功能各自实现词法规则，容易在注释、引号、占位符和多语句边界上产生分歧；若把 Database Tools 类型放入主描述符，禁用可选插件时又会破坏非数据库能力。快速执行还存在误执行写语句、DDL 自动提交、取消不及时和明文日志泄漏风险。

## 决策

1. 日志还原、占位符计数/重写和风险分类共享同一字符级 SQL 词法状态机；只替换正常 SQL 上下文中的 `?`，结构不闭合时返回类型化失败；
2. 转换采用“可证明成功，否则拒绝或显式降级”：CREATE TABLE 复用 S8 schema/生成引擎；SELECT 必须显式投影，复杂表达式必须 `AS`；未知 JDBC 类型只生成 `Object`/`OTHER` 并显示人工确认警告；
3. Java 转 DDL 只消费 PSI 与公开注解值，不反射、不实例化、不运行项目代码或注解处理器；
4. XML 格式化先在内存形成完整候选，再预览、复核文档修改戳，并以一个 IDE Command 写入；结构错误、只读或 TOCTOU 变化时不写；
5. 执行核心不依赖 Database Tools，只产生已校验计划和短生命周期授权对象；实际后端、数据源选择和 UI 全部位于数据库可选描述符；
6. 执行只允许单条 SQL、显式参数类型、1 MiB SQL 和 500 参数上限；写入/DDL/未知语句必须完成风险确认和精确短语二次确认；
7. 数据库后端使用受管连接引用和显式事务，设置 30 秒超时、200 行上限，并由进度取消主动调用远程 statement cancel；只读完成后回滚，危险语句成功后提交，失败与取消回滚；
8. 不调用日志 API记录 SQL、参数、结果、凭证或项目路径；计划、参数、授权和结果对象重写字符串表示，只输出计数、风险、状态码等非内容元数据；
9. 测试骨架支持 JUnit 4/5，但始终只预览；不创建文件、不启动框架、不连接数据库；无法安全表达的泛型来源明确拒绝。

## 结果

- 主插件在 Database Tools 缺失时仍保留日志、格式化、转换、参数校验和测试骨架；
- 用户在任何写文件、写数据库或未知 SQL 之前都能看到明确边界并主动确认；
- SQL 字符串只在短生命周期内存与用户可见结果面板中出现，不进入插件日志；
- 部分数据库会自动提交 DDL，插件不能承诺回滚，因此必须在第一次确认中明确提示；
- SELECT 结果类型没有数据库元数据时不能保真，首版选择 `Object`/`OTHER` 与警告，不猜测 Java 类型。
