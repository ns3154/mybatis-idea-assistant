## 1. 交付范围

本阶段交付统一的只读语义底座，不增加写用户文件功能：

- XML 符号：精确区分 Mapper namespace、四类 statement、`resultMap` 和 SQL fragment；
- 安全索引：索引器只读取 `FileContent`，使用不解析实体的轻量 XML 扫描，不创建 PSI；
- Mapper 模型：支持 Java、Kotlin K2 light class、继承泛型方法、参数、返回实体和注解 SQL 来源；
- 来源证据：支持 XML namespace、`@Mapper`、`@MapperScan`/`@MapperScans` 和 MyBatis XML 配置；
- 项目配置：增量解析 MyBatis XML、Spring Boot/MyBatis-Plus properties/YAML 配置；
- TypeAlias：支持内置别名、显式别名、包扫描、`@Alias`、冲突候选和大小写不敏感查询；
- 模块边界：statement、配置、TypeAlias、MapperScan 和 XML → Java 查询只返回当前模块及依赖可见结果；
- 生命周期：未保存编辑、文件移动/删除、项目根变化、Dumb Mode、索引竞态、项目关闭和取消均精确失效或保守降级。

S3 的完整引用、更多 Inspection 和 Quick Fix 不属于本阶段，不以 S2 底座完成替代其验收。

## 3. 正确性与性能证据

| 场景 | 验收结果 |
|---|---|
| 统一 XML 键 | 符号类型、namespace、id 共同组成稳定键；同名 `resultMap`、SQL fragment、statement 不串类 |
| 重复声明 | 同一键的多文件、多 XML 声明全部保留，不静默选择首个 |
| 不完整/恶意 XML | 不完整 XML 不入索引；内部/外部实体不解析；前缀属性和嵌套伪声明不误收 |
| 10 万 statement | 同一测试内生成、提交、通过真实 `FileBasedIndex` 建索引并精确查询首中尾键，测试通过 |
| Mapper 继承 | 继承方法、泛型参数和返回类型按当前 Mapper 完成替换 |
| Kotlin K2 | 通过 Java light class 建立 Mapper、继承方法、可空实体和注解 SQL 模型 |
| 配置 | MyBatis XML 与 Boot/MyBatis-Plus properties/YAML 合并，宽松命名和未保存修改均可见 |
| TypeAlias | 内置、显式、默认、包级、`@Alias` 和冲突候选均通过；类名目录按上下文缓存 |
| 多模块 | 无依赖模块隔离；增加依赖后可见；项目根变化触发失效；反向导航同样遵守 XML 模块作用域 |
| 缓存 | Mapper/声明源文件、XML/配置索引、MapperScan、项目根和 Dumb 状态分别参与失效；无关 Java/XML 修改复用语义快照 |
| 查询取消 | 扫描、候选循环和定位查询均传播平台取消异常，不吞取消、不无界重试 |

这里的“无项目扫描”指不遍历项目文件系统。TypeAlias 包解析通过平台类名索引建立按上下文缓存的目录，不在编辑器路径枚举文件。
