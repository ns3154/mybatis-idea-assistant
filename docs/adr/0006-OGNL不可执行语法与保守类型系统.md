# ADR-0006：OGNL 不可执行语法与保守类型系统

- 状态：已接受
- 日期：2026-08-12
- 决策范围：S6 词法、语法、注入 PSI、类型、引用和重构
- 关联文档：`docs/S6-OGNL语言支持任务卡.md`

## 背景

MyBatis OGNL 同时包含 Java 风格属性/方法链、字符串和集合字面量、索引、逻辑关键字、三元、静态成员与上下文变量。把表达式拆成点路径会丢失优先级和词法作用域；直接调用 OGNL 运行库求值又可能初始化项目类、执行方法或读取运行期状态，不适合作为 IDE 分析基础。

## 决策

### 1. 解析与执行彻底分离

自有词法器和 Pratt 语法器只生成不可变 AST 与稳定诊断。生产分析不调用 OGNL 求值器、不通过反射执行项目方法，也不为“验证表达式”初始化用户类。测试可以用公开规范和自行编写语料核对结构，但不复制第三方实现。

### 2. 一个 AST 驱动平台 PSI

纯解析核心保存半开范围、token 和错误恢复结果；IntelliJ ParserDefinition 使用同一 token/优先级规则构建注入 PSI。`test`、`when/test`、`bind/value` 只通过宿主选择器区分，不复制语法。宿主 XML 范围与 S5 source range 都保持可逆。

### 3. 类型结果区分确定、未知和失败

类型推导使用 S4 参数模型、S5 词法绑定与 Java/Kotlin 公共 PSI。动态 Map 键、原始集合、动态索引、重载歧义返回 unknown；Dumb/失效/项目关闭返回生命周期结果；只有确定的不存在属性或方法才能形成 Inspection。

### 4. 词法作用域按动态树位置计算

Mapper 参数与 `_parameter` 位于根作用域；bind 只对同一有序序列后续节点可见；foreach item/index 只在 body 内可见；include property 不冒充运行期 OGNL 变量。作用域查询可缓存，但依赖 S5 program、源文件和索引世代精确失效。

### 5. 重构只消费稳定引用

精确参数、JavaBean 属性、方法或静态成员可以建立平台引用；Map 动态键、字符串拼接出的名称和多目标不建立可写引用。Rename 复用平台预览、冲突检查和单次 Undo，不使用全文替换。

## 后果

- S6 能在不执行用户代码的前提下提供语法、类型和导航；
- 纯解析核心可做大规模随机测试，平台 PSI 只承担集成验证；
- 一些运行期合法的动态对象表达式会保持 unknown，这是避免误报的刻意边界；
- S7 可以消费带类型与源范围的表达式，但不能假设所有 OGNL 都可静态求值。
