# 隐私说明

> 适用于 MyBatis Assistant 当前源码与由本仓库正式发布的插件包。

## 结论

MyBatis Assistant 默认离线运行，不包含统计、遥测、广告或用户画像功能，也不会把项目源码、SQL、数据库结构、凭据或 MCP 数据上传给维护者。插件的网络访问总开关、本地 MCP 服务和 MCP 写工具均默认关闭。

## 本地处理的数据

为提供导航、检查、补全、重构、预览和生成能力，插件会在当前 IDE 进程内读取：

- 当前项目的 Java、Kotlin、XML、YAML 与属性文件 PSI、索引和模块结构；
- 用户主动粘贴或选择的 SQL、DDL、日志片段、表、列和生成目标；
- Database Tools 已经加载到 IDE 内存中的数据源与结构模型；
- 用户显式配置并主动加载的 Community JDBC 元数据。

这些数据用于本机计算，不会由插件发送给维护者。插件生成的代码、预览、设置和索引仍保存在用户的 IDE、项目或构建目录中，其保留周期由用户和 IntelliJ Platform 控制。

## 数据库与凭据

- Database Tools 适配只读取 IDE 已加载的模型，不会为补全或检查主动连接、刷新数据库或弹出凭据框。
- Community JDBC 必须由用户显式配置驱动 JAR、JDBC URL、用户名和 schema，并由用户主动触发加载；插件不会下载 JDBC 驱动。
- JDBC 密码只交给 IntelliJ Platform PasswordSafe，不写入项目文件、设置导出、日志、MCP 响应或插件 ZIP。
- MCP 数据库工具只返回有界的数据源、表、列和类型摘要，不返回密码、完整 JDBC URL、用户名或本地驱动路径。

数据库服务器、JDBC 驱动和 IntelliJ Platform 自身可能有独立的日志、网络和隐私行为；这些行为不由本插件控制，应按相应产品的隐私说明和组织策略评估。

## 本地 MCP 服务

- MCP 默认关闭；关闭时不创建监听端口、线程池或会话。
- 启用后仅绑定 `127.0.0.1`，只服务当前已打开项目；每次服务启动生成新的内存令牌。
- 令牌不会写入设置、项目、导出文件或日志，只能通过用户主动执行“复制 MCP 连接配置”取得。
- 请求还必须通过 Host、Origin、Bearer token、会话、请求体上限和工具白名单校验。
- 写工具另有独立开关，且必须执行 `preview` 后再用一次性短期确认令牌执行；确认时重新检查文件状态，并复用 IDE Command、Undo 和失败回滚。
- 关闭 MCP、关闭项目或更改端口会释放监听器并使原令牌与会话失效。

因为 MCP 客户端是用户自行选择的软件，客户端如何存储连接配置、处理返回内容或调用外部模型不属于本插件控制范围。把连接令牌交给客户端前，请核对客户端的权限与隐私政策。

## 设置、日志与导出

- 全局非敏感设置保存在 IntelliJ 的 `mybatisAssistant.xml`；设置 schema 当前为 v2。
- 设置导出格式只包含公开开关、端口、工具白名单和界面语言，不包含密码、MCP 令牌、数据库凭据或运行期会话。
- 损坏、超限、重复键、敏感键或未知未来版本的导入会整体拒绝，不覆盖当前有效设置。
- 插件不会把访问令牌、密码或私钥写入自己的通知和异常文案。用户主动处理的 SQL、DDL、日志或数据库错误可能显示在当前 IDE 的预览或错误界面中，请勿把未经脱敏的截图和日志公开提交。

## 网络访问与第三方服务

当前插件不包含维护者运营的云端服务。允许网络访问后，只有用户显式配置和触发的本地开发能力可以使用相应连接；本插件不会因此自动上传项目内容。Gradle 构建、依赖下载、JetBrains Marketplace、IDE 更新和 GitHub Actions 属于开发或分发基础设施，不是插件运行期遥测。

## 用户控制

用户可以随时：

- 在“设置/工具/MyBatis Assistant”关闭网络访问、MCP 或 MCP 写工具；
- 清空 MCP 白名单、关闭项目或重启服务以旋转令牌；
- 删除 Community JDBC 数据源及其 PasswordSafe 凭据；
- 恢复默认设置，或卸载插件并按 IntelliJ Platform 的方式删除残留设置和缓存。

发现隐私或安全问题时，请按[安全策略](../.github/SECURITY.md)使用 GitHub Security Advisory 私密报告，不要在公开 Issue 中提交凭据、源码或真实数据库信息。
