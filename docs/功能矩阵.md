# 功能矩阵

> 矩阵版本：0.2
> 范围：B01 Mapper 方法到 XML statement，以及 B02/B03 精确解析增量
> 语义原则：首批只做精确匹配；不以猜测换取“看起来能跳转”

## 1. 状态与优先级说明

- `P0`：首批纵切面不可缺少，错误会使核心结果不可信；
- `P1`：首批体验或稳定性的重要保障；
- `P2`：后续增强，不阻断首批交付；
- `语料就绪`：已有可供实现和测试使用的输入；
- `待实现`：行为已确定，尚未交付代码；
- `后续`：明确不进入 B01。

## 3. 首批精确语义

### 3.1 Mapper 键

```text
mapperKey = Java 接口全限定名
xmlMapperKey = XML mapper/@namespace 的完整字符串
```

仅当两个字符串完全相等时，Mapper 与 XML 才关联。首批不解析 type alias，不根据 XML 文件名推断 namespace，也不做简单类名兜底。

### 3.2 Statement 键

```text
methodKey = Java 接口全限定名 + "#" + Java 方法名
statementKey = XML namespace + "#" + statement/@id
```

首批不做参数级 Java 重载消歧。正向 Java → XML 遇到重载时返回“不支持的源”且不显示 gutter，避免把单个重载误称为唯一映射；反向 XML → Java 遇到重载时保留全部同名方法，由平台展示候选。

### 3.3 B02 结果类型

以下类型是 B02 已实现并通过统一质量门的稳定语义：

解析层至少区分以下结果，避免上层依赖异常文本：

| 结果 | 含义 | 导航行为 |
|---|---|---|
| `唯一匹配` | 稳定键恰有一个有效目标 | 直接导航 |
| `无 Mapper XML` | namespace 无匹配 XML | 不导航 |
| `statement 缺失` | namespace 已匹配，方法名无 statement | 不导航 |
| `多候选` | 稳定键有多个有效目标 | 展示候选 |
| `索引未就绪` | Dumb Mode 或索引不可查询 | 静默降级并允许稍后重试 |
| `源已失效` | 查询期间 PSI 或项目生命周期失效 | 取消当前动作 |
| `不支持的源` | 调用方传入非本批支持的 Java 源 | 不导航，不尝试猜测 |

namespace marker 与 statement 键写入同一个 `FileBasedIndex`，索引版本升级为 2。这样零个 statement 候选时，解析层仍能区分“没有对应 Mapper XML”和“Mapper XML 存在但 statement 缺失”。

## 6. B03 反向导航语义

```text
mapper/@namespace 完整值 ──精确 FQN──> Java 接口
statement/@id          ──精确方法名──> 当前接口声明的方法候选
```

- 只接受全限定名完全相等的接口，不按 XML 文件名或简单类名兜底；
- 一个同名方法时直接导航；Java 重载产生多个候选时全部保留并交由平台展示；
- 不把继承方法、参数签名推断或框架基类扩展混入 B03；
- Dumb Mode、无精确接口、源失效或 XML 结构不支持时不导航。
