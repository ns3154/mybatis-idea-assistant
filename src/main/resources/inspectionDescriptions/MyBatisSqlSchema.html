检查 MyBatis statement 的代表性虚拟 SQL 是否引用当前完整数据库元数据中不存在或不唯一的表、列，并在单表目标唯一时检查 ResultMap 缺列和基础 Java/JDBC 类型不匹配。 当 ResultMap 根类型、可写属性、已映射字段和物理表都能唯一确定时，提供“补齐未映射字段”的信息级安全修复；修复支持预览和单次撤销，并在元数据变化、目标变化、只读或冲突时停止。 检查只消费后台已经完成的 READY 快照，不会在编辑器线程连接数据库、刷新元数据或等待 I/O。 数据源断开、加载中、多表或多目标上下文、复合 ResultMap column、动态表列、SQL 语法不完整或 Database Tools 不可用时保持静默。
