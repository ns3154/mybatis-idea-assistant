# S1 插件骨架与流水线任务卡

> 阶段：S1 现代插件骨架与质量流水线
> 日期：2026-08-11
> 状态：本机与沙箱已验，待远端 CI 统一门禁

## 目标

在不扩展 S2 以后业务语义的前提下，建立可重复构建、可安装、可升级、可禁用、可卸载、可诊断的 IntelliJ IDEA 2026.1 插件基础设施。

## 范围

- IntelliJ Platform Gradle Plugin 2.x、Java 21、Gradle 9.3 和 261 基线；
- 主描述符及 Kotlin、Spring、YAML、Database Tools 四个可选依赖描述符；
- 中文设置页、持久化状态、默认离线策略；
- 通知分组、取消传播和异常隔离；
- Checkstyle、JaCoCo、依赖锁定、Plugin Verifier 与 CI 报告；
- ZIP 安装、升级、禁用、启用、卸载、重装和重启；
- 20 次沙箱启停，以及四类可选依赖分别禁用和全部禁用时的启动隔离。

## 任务与验收

| 编号 | 任务 | 验收标准 |
|---|---|---|
| S1-01 | 构建与描述符 | `verifyPluginProjectConfiguration`、`verifyPluginStructure`、`verifyPlugin` 无阻断 |
| S1-02 | 平台基础设施 | 设置、通知、异常隔离由真实扩展注册测试覆盖 |
| S1-03 | 静态质量门 | Checkstyle 零告警；整体行覆盖率不低于 70%，核心语义包不低于 85% |
| S1-04 | 供应链基础 | Gradle Wrapper 校验和、依赖锁文件、Dependabot 与只读 CI 权限齐全 |
| S1-05 | 沙箱生命周期 | 连续启动/关闭 20 次，每次加载插件、退出码为 0、本插件异常数为 0 |
| S1-06 | 可选依赖隔离 | Kotlin、Spring、YAML、Database Tools 分别禁用及全部禁用共 5 组均可加载 |
| S1-07 | 真 IDE ZIP 生命周期 | 本机 IDEA 2026.1 完成安装、升级、禁用、启用、卸载、重装和重启 |
| S1-08 | 远端门禁 | 推送后 GitHub Actions 全绿，并保留测试、覆盖率、静态检查和 Verifier 报告 |

## 复现命令

```bash
mvn --batch-mode --file samples/java-mybatis-minimal/pom.xml clean verify
mvn --batch-mode --file samples/semantic-corpus/pom.xml clean verify
./gradlew check verifyPluginProjectConfiguration verifyPluginStructure verifyPlugin
./scripts/verify-sandbox-lifecycle.sh 20
./scripts/verify-optional-dependency-isolation.sh
```

真实 IDE 操作必须只改动 `MyBatis Assistant`，不得修改用户已安装的其他插件；人工窗口固定放在副屏幕。
