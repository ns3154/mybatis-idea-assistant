# S13 性能、可靠性、跨版本与正式交付任务卡

> 日期：2026-08-12
> 状态：执行中
> 目标：关闭《交付阶段实施规划》的全部 1.0 阻断门；自动化证据与真实 IDE 证据分开记录，任何一项不得相互替代。

## 1. 支持矩阵

IntelliJ IDEA 最近四个稳定大版本按 2026-08-12 官方发布状态确定为：

| 大版本 | 交付验证版本 | 构建角色 |
|---|---|---|
| 2025.2 | 2025.2.6.2 | 最低编译 SDK、`since-build=252`、每次提交阻断 |
| 2025.3 | 2025.3.6 | 定时/手动 Plugin Verifier |
| 2026.1 | 2026.1.4 | 定时/手动 Plugin Verifier 与当前实机候选 |
| 2026.2 | 2026.2.0.1 | 定时/手动 Plugin Verifier 与最高稳定版候选 |

Android Studio 2026.1.2.10 继续作为无 Spring/Database Tools 环境的保守降级验证。编译必须使用最低受支持 SDK；只修改 `since-build` 而仍以高版本 SDK 编译不算兼容证据。

## 2. 自动化任务

### S13-A 四版本兼容

- 生产源码必须在 2025.2.6.2 SDK 上编译；2025.2 的旧注解目标、公共 API 与字节码约束均为阻断。
- Plugin Verifier 对四个 IDEA 稳定大版本不得出现兼容问题、内部 API、计划移除 API或实验 API。
- 兼容工作流每周及手动运行，五个矩阵作业失败互不取消，报告全部保留。

### S13-B 三系统无界面回归

- Linux 使用 `ubuntu-24.04`，macOS 使用 `macos-15`，Windows 使用 `windows-2025`。
- 每个平台执行双 Maven 语料、全部平台测试、覆盖率、Checkstyle、项目配置与插件结构验证。
- 该工作流只证明跨系统后台自动化，不替代安装、索引、编辑、生成、Undo 和卸载的真实 IDE 操作。

### S13-C 大型项目与性能

- 核心压力夹具固定为 100 万行、2000 个 Mapper、10000 个 statement、四模块、四数据源维度。
- 每个 Mapper 独立扫描并校验 namespace 与全部 statement，单 Mapper 扫描 P95 不高于 50ms。
- 保留既有 10 万 statement 单文件、千表 SQL 分析、100 方法冷热导航、动态 SQL/OGNL/方法名取消与性能门。
- 所有长循环继续传播平台取消；不得以关闭测试或放宽阈值处理回归。

### S13-D 安全、恢复与供应链

- 运行依赖锁、Dependabot、漏洞告警、SBOM 可复现、ZIP 内容和敏感字段检查。
- 所有写操作继续覆盖 preview、TOCTOU、冲突停止、单次 Undo/Redo 与中途异常回滚。
- MCP 默认关闭、只监听回环、令牌只驻内存；意外运行期异常只写本机诊断日志并向客户端返回不含路径/堆栈的安全错误。
- 发布工作流缺签名材料必须失败关闭；签名私钥、密码和 Marketplace token 只从 CI secret 注入。

## 3. 真实 IDE 阻断任务

以下任务必须在副屏或独立测试机执行，当前不得占用用户主屏：

1. 最近四个 IDEA 大版本分别安装候选 ZIP，完成项目导入、索引、Java/XML 双向导航、Inspection、补全、生成、Undo 和卸载冒烟。
2. macOS、Windows、Linux 各完成安装、索引、编辑、生成、禁用、启用、卸载、重装和重启。
3. Alpha→Beta→RC→正式候选及反向降级逐级验证设置迁移、默认离线、MCP 端口释放和项目文件无隐式修改。
4. 当前最终产物执行 100 次 IDE 启停、项目打开/关闭和索引重建，核对插件加载、关闭、错误栈、线程与后台任务残留。
5. 在真实大型项目编辑期间观察 UI 冻结、EDT 阻塞、索引风暴和稳定内存；出现可复现问题即恢复为发布阻断。

每次真实验收必须记录：IDE/系统/架构、插件版本与 SHA-256、步骤、结果、IDE 日志范围、失败截图或复现方式。没有副屏或独立机器时保持“待验”，不得以平台测试、Plugin Verifier 或历史版本证据替代。

## 4. 发布与用户资料

- 用户资料必须包括安装与首次使用、兼容矩阵、常见问题与故障排查、隐私、第三方组件/SBOM、发布升级回滚和变更记录。
- 新用户路径目标为 15 分钟内完成安装、识别 Mapper、Java/XML 跳转和第一次安全生成预览。
- Alpha、Beta、RC 只收集用户主动提供的最小问题信息；插件不增加遥测或自动上传。
- 正式版必须使用唯一语义版本、验证签名、SHA-256、SBOM、Git 标签、GitHub Release 与 Marketplace 制品；同一版本不得重建覆盖。

## 5. 自动化验收命令

```bash
mvn --batch-mode --file samples/java-mybatis-minimal/pom.xml clean verify
mvn --batch-mode --file samples/semantic-corpus/pom.xml clean verify
./gradlew clean check verifyPluginProjectConfiguration verifyPluginStructure verifyPlugin
go run github.com/rhysd/actionlint/cmd/actionlint@v1.7.7 .github/workflows/*.yml
```

定时/手动远端门：

- `compatibility.yml`：四个 IDEA 稳定大版本与 Android Studio。
- `cross-platform.yml`：Linux、macOS、Windows 无界面完整回归。
- `release.yml`：完整质量门、签名、签名验证、SBOM/SHA-256、可选 Marketplace 和草稿 Release。
